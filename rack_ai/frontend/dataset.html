กลับภาพสด

กำลังโหลด

1. นำเข้าหรือเลือกคลิปดิบ

รองรับ MP4, MOV, AVI, MKV และ M4V สูงสุด 5 GB ระบบตรวจต้น/กลาง/ท้ายคลิปก่อนเพิ่ม ห้ามใช้วิดีโอที่มีกรอบ AI ฝังอยู่
คลิปที่อัปโหลดใช้คัดภาพเพื่อเทรน หรือกันไว้ใส่จำนวนจริงเพื่อทดสอบการนับได้ ทุกภาพต้องผ่านคนตรวจ

2. ตรวจและแก้กรอบ

เลือก “เพิ่มกรอบ” แล้วลากบนภาพ หรือเลือกกรอบเดิมแล้วลากย้าย/ลากมุมขวาล่างเพื่อปรับขนาด

กรอบต้องครอบทีละเก๊ะ แม้อยู่ติดกัน ต้องตรวจให้ครบทั้งภาพ

3. ตีกรอบด้วย Roboflow

ส่งออกภาพพร้อมกรอบที่โมเดลเสนอเป็น YOLOv8 แล้วแก้กรอบใน Roboflow โดยใช้โปรเจกต์ชนิด Object Detection และคลาสเดียวชื่อ rack

เปิด Roboflow ↗
ห้ามเปลี่ยนชื่อไฟล์ภาพใน Roboflow เมื่อนำกลับ ระบบจะจับคู่ด้วยชื่อ frame_... หากไม่เลือกอนุมัติ ภาพจะกลับมาอยู่สถานะรอตรวจในหัวข้อ 2

4. สร้างชุดฝึกและตรวจคุณภาพ

ต้องมีอย่างน้อย 3 คลิปหรือช่วงบันทึกอิสระ ระบบจัดแต่ละคลิปทั้งชุดให้อยู่ train / val / test ชุดเดียว และปฏิเสธภาพซ้ำข้ามชุด

    5. เทรนและเปรียบเทียบโมเดล

    ชื่อนี้ใช้แสดงในระบบเท่านั้น ไฟล์น้ำหนักยังคงชื่อ best.pt เพื่อไม่กระทบการโหลดโมเดล สามารถเปลี่ยนชื่อภายหลังได้

    คลิปทดสอบการนับที่กันไว้

    เลือกคลิปทดสอบด้านบนก่อนกดเปรียบเทียบโมเดล ผลตรวจจับและผลนับจะแสดงแยกกัน

      6. ทดสอบโมเดลพร้อมดูวิดีโอ

      แสดงกรอบ Track ID เส้นสีม่วง และยอดนับ ใช้ไฟล์ RAW และรันแยกจากกล้องสด เลือก “โมเดลที่ใช้งานอยู่” หรือรุ่นที่เทรนแล้วได้
